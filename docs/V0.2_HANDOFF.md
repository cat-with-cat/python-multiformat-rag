## Verified with real components

- Four synthetic Chinese formats: TXT, CSV, text-layer PDF, PPTX.
- Unicode cleaning and per-format metadata.
- LlamaIndex `SentenceSplitter`.
- `BAAI/bge-small-zh-v1.5` on CPU, 512 dimensions.
- Seven source units / seven chunks.
- Local vector-index persistence and reload.
- Top-K cosine retrieval with `score >= 0.35`.
- `source_file`, `file_type`, `source_id`, `chunk_index`, plus row/page/slide
  locators in retrieval results.
- A–F retrieval evidence, including two-source synthesis and an indirect prompt
  injection sample.
- Authenticated OpenLux model listing: HTTP 200, 333 parsed model IDs, exact match
  for `gemini-3.1-flash-lite`.
- Six OpenLux Chat Completions calls after explicit user authorization, exactly
  one per A–F scenario and no retry.
- A–F real answers: 6/6 PASS, including grounded refusal for C/D, injection
  resistance for E, and correct citation/source mapping for A/B/E/F.

## Verified only with Mock or static checks

- Prompt construction and numbered source labels.
- No-result short-circuit to `未在文档中找到相关依据。`.
- Empty LLM response fallback.
- Provider exception wrapping without leaking provider details.
- Prompt delimiter escaping.
- Missing-Key CLI error before model/index loading.
- OpenAI-compatible request formatting and custom Base URL/model selection.
- Safe OpenLux-compatible timeout, auth, model, rate-limit, server, malformed,
  and empty-response handling using Mock HTTP transport.
- Full Mock test suite: 46 passed; the pytest suite itself makes no real LLM call.
- Missing-key CLI tests are isolated from the developer `.env`; the initial
  post-key run failed 2 tests for this reason, then passed after the test-only fix.

## Not yet verified

- Exact OpenLux charged amount and account-specific pricing multiplier.
- Long-context truncation behavior near the 8,000-character application cap.
- Citation enforcement inside production code; citations are evaluated by the
  validation harness after generation.

The local OpenLux key was used without printing its value, prefix, or length and
remains only in the ignored `.env` file.
